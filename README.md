# NexusERP - Enterprise Resource Planning System

A full-stack MERN ERP system built during internship.

## 🚀 Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js + Express.js
- **Database:** MongoDB Atlas

## 📦 Modules
- Dashboard with analytics
- Product Management
- Customer Management
- Supplier Management
- Sales Orders
- Purchase Orders
- Goods Receipt Notes (GRN)
- Invoice Management
- User Management

## ⚙️ Setup Instructions

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm start
```
